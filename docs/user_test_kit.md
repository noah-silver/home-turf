# Home Turf user test kit (about 15 minutes per person)

The rubric's strongest evidence is "a real user tried it." This kit makes each test quick and gives you numbers for the report. Run it with 3–5 people: classmates, USC or other alumni friends, run-club members, and, if you can, one bar manager or alumni-club organizer.

## Before you start
- Run the app on your laptop (`python app.py`) and open http://127.0.0.1:8050.
- Keep a stopwatch (phone timer) and this sheet open.
- Ask: "Can I quote you by first name and school or role in a class report?" Record yes or no.

## Task 1: the old way (baseline), max 5 minutes
"You're visiting **[a city they don't live in]** this weekend and want to watch **[their team]** with other fans. Using Google, Reddit, or anything you like, find the bar where the team's fan club watches, and tell me how sure you are it's current."
- Time to an answer: ____ min ____ s (or "gave up at 5:00")
- Confidence it's right and current (1–5): ____
- Sources they used: ____________________

## Task 2: Home Turf
"Now do the same in Home Turf." (Same team and city. If it was already cached, pick a new pair.)
- Time to an answer: ____ s
- Confidence (1–5): ____
- Did they open the sources or the evidence quote? Y / N
- Was the answer the same as Task 1? Same / different / Task 1 found nothing

## Task 3: club president role (if they've ever organized a group)
Log in as a demo club president. "Find a home bar for the season, then plan a rivalry watch party."
- Could they do it without help? Y / N. Where did they get stuck? ______________
- "How long does picking a bar for the season take you today?" ____ hours
- "Would you use this instead? Why or why not?" ______________
