How the agents work

8 agents on gpt-6-luna · fixed pipelines, not a free-roaming boss · code does the facts, the model does judgment · people make every commitment

Demo: every team's fans, on one map

  • Team-logo pins, ringed by verification status
  • Filter by league: NFL · NCAA · MLB · NBA · NHL · Soccer
  • Any team + city: verified in ~7 s for ~1–2¢

Demo: Yale vs. Princeton in New York

  • Finds Yale–Princeton (Nov 14), neutral bar for 125
  • 3 drafted invitations, nothing sent
  • Click any bar: photos, reviews, Street View
  • Confirmed only after all 3 parties approve · $0.0007

  • Matchmaker $0.0010 · rivalry plan $0.0007 · pitch $0.0003 · Guard $0.00009
  • Cost cuts: result cache, code-first Verifier (8/18 settled free), search caps, low reasoning effort
  • Experiment: 1 search vs 3 = 12% cheaper, same quality; medium effort = 26% pricier, fewer verified spots

Safety: built, tested, shown

  • Injection blocked by free filter, then Guard agent
  • Model never writes addresses or map pins
  • No agent can book, send, or approve
  • Caps per action, session, day · URL allowlist
  • 22/22 safety + feature tests pass

What's next

  • Real supply: 5 bars + 5 clubs in one city, business verification, real accounts
  • Fans as verifiers: post-game “was the club here, was the sound on?”
  • Send with approval: email invitations only after a human clicks send
  • Adaptive Scout: 1 search first, escalate only if nothing verifies
  • Hosted + mobile, and the MCP server so assistants can use Home Turf
  • Business model: bars pay $49/mo for Pro (pitch clubs, bookings, labeled Featured slot, analytics); alumni associations license a white-label finder ($5–25k/yr). Fans stay free; AI is about 1.4¢ per user per month
The ask: a Yale Alumni Association club (start with the Yale Club of New York) and one partner bar to run a real season pilot.
