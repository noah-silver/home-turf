Home Turf

AI agents that find where your team's fan club watches the game in any city, verified, and help clubs and bars team up for the season.

How the agents work

8 agents on gpt-6-luna · fixed pipelines, not a free-roaming boss · code does the facts, the model does judgment · people make every commitment

  • Matchmaker $0.0010 · rivalry plan $0.0007 · pitch $0.0003 · Guard $0.00009
  • Cost cuts: result cache, code-first Verifier (8/18 settled free), search caps, low reasoning effort
  • Experiment: 1 search vs 3 = 12% cheaper, same quality; medium effort = 26% pricier, fewer verified spots

Safety: built, tested, shown

  • Injection blocked by free filter, then Guard agent
  • Model never writes addresses or map pins
  • No agent can book, send, or approve
  • Caps per action, session, day · URL allowlist
  • 17/17 safety tests pass

What's next

  • Send with approval: email invitations only after a human clicks send
  • Adaptive Scout: 1 search first, escalate only if nothing verifies
  • Hosted + mobile, and the MCP server so assistants can use Home Turf
